# WonderVault-Dove_i_tuoi_sogni_diventano_realta..._a_portata_di_click.
Il progetto prevede la realizzazione di un sistema e-commerce dedicato esclusivamente alla vendita e alla gestione di prodotti a tema Disney (merchandising, abbigliamento, oggetti da collezione, ecc.). Il titolo di questo progetto è appunto “WonderVault: Dove i tuoi sogni diventano realtà... a portata di click.”.
